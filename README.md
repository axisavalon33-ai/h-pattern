# MEDSCOPE II – Exhibition screen

Silent, looping Smart-TV screen for the MEDSCOPE II Neurosurgery & Neuroscience
exhibition (English / தமிழ் / සිංහල).

- `index.html` – the whole screen (all text is in the `UI` and `SLIDES` lists at the top of the script)
- `start-tv.bat` / `start-tv.sh` – start a local web server on port 8000
- `start-kiosk.bat` – opens the screen straight from the files, locked full screen, in Chrome or Edge (for the OPS computer in a touch TV; no Python needed)
- `HOW-TO-RUN.txt` – step-by-step instructions for exhibition day
- `fonts/` – Oswald, Atkinson Hyperlegible, Noto Sans Tamil, Noto Sans Sinhala (SIL Open Font License)
- `videos/` and `images/` – put `menu.mp4`, `01.mp4`…`10.mp4` and `background.jpg` here

The Tamil and Sinhala text must be checked by native speakers before use.
